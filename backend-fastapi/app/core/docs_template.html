Base URL & Environments

All API requests must be served over HTTPS. The following base URLs are configured for ParyatakRoute:

Production & Development Base URLs 
# Production Endpoint (Authoritative)
https://paryatakrouteapi.itspranjal.in/api/v1

# Local Development Endpoint
http://localhost:8000/api/v1

Quick Start

Make your first request to verify connectivity using the public destination search or health probe: 

curl -X GET "https://paryatakrouteapi.itspranjal.in/api/v1/destinations?query=Jaipur&limit=5" \
  -H "Accept: application/json"

Authentication Overview

ParyatakRoute uses Supabase JWT Bearer Tokens for session authentication. Protected endpoints require the standard Authorization header:

Authorization Header Format 
Authorization: Bearer <your_access_token>

⚡ Quick Testing with Demo Account

You can immediately test authenticated routes using the configured demo account (demo@paryatakroute.in / Demo@12345), or click the ⚡ Autofill Demo Token button inside any endpoint card below to obtain a bearer token in 1 click!

API Architecture & Capabilities

  • AI-Powered Itinerary Generation: Dynamic day-by-day scheduling powered by Groq LLM (llama-3.3-70b-versatile) with multi-day chunking and fallback deterministic structuring.
  • Surgical Day Regeneration: Re-plan a specific day in an existing itinerary without altering preceding or subsequent days.
  • Deterministic Budget Engine: Real-time categorization into Accommodation, Transport, Food, Activities, and Miscellaneous.
  • Geospatial Routing: Real-time driving distance, geometry, and duration calculated via Project OSRM.
  • Live Meteorological Forecasts: 7-day weather predictions with precipitation probabilities via Open-Meteo.
  • ReportLab PDF Export: Server-side high-resolution printable PDF generation.
  • Tenant Isolation: Broken Object Level Authorization (BOLA) protection with Supabase Row Level Security (RLS).

Standard Error Responses

ParyatakRoute returns a unified JSON error envelope across all endpoints:

Error Response Envelope 
{
  "success": false,
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Authentication token is missing or invalid",
    "details": null
  }
}
400 BAD_REQUEST
Malformed request syntax, invalid parameters, or date constraint violations.
401 UNAUTHORIZED
Missing, expired, or malformed JWT Bearer authentication token.
403 FORBIDDEN / BOLA_VIOLATION
Attempted access to trip or itinerary belonging to another tenant user.
404 NOT_FOUND
Requested trip ID, itinerary ID, or user profile could not be located.
409 CONFLICT
Duplicate registration email or destination already bookmarked in favourites.
422 VALIDATION_ERROR
Pydantic schema validation failure on request payload or query parameters.
